# Procedure: Triad Co-Evolution Loop
## Purpose
Execute one complete cycle of the AXIOM → ENTROPY → NEXUS co-evolution mesh.

## Prerequisites
- All three nodes are initialized
- GOALS.md is readable for leaf-node selection
- SKILLHUB directory structure is intact

## Steps
1. **AXIOM (Generator):** Read GOALS.md, decompose highest priority leaf node into implementation plan
2. **AXIOM (Generator):** Generate new skill or mutate existing tier_1_active skill
3. **AXIOM (Generator):** Write skill to pyramid structure with proper watermark
4. **ENTROPY (Adversary):** Execute all test harnesses against the skill
5. **ENTROPY (Adversary):** Inject adversarial edge cases and malicious payloads
6. **NEXUS (Synthesizer):** Run SafetyGate verification on all outputs
7. **NEXUS (Synthesizer):** Apply patches from entropy findings
8. **NEXUS (Synthesizer):** Commit to tier_1_active if tests pass
9. **Shared:** Evaluate dynamic thresholds (>5% token reduction or patched ERR_*)
10. **Shared:** Update SKILLHUB registry and GOALS.md status

## Verification
- All new/modified skills have passing test harnesses
- No [ERR_SYNTAX], [ERR_LOGIC], [ERR_BLOAT] markers in degraded files
- PYRAMID structure integrity maintained
