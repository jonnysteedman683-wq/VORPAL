## Lessons learned

- `hermes skills install <user>/<repo>` fails for GitHub repos not indexed by skills.sh — must clone manually
- Windows MSYS path mangling breaks `install.sh` scripts — manual file copy is the workaround
- Security scanner blocks community skills with `os.getenv("API_KEY")` patterns — false positive, manual install bypasses it
- Always restart gateway after plugin config changes
- Hermes venv Python is at `%LOCALAPPDATA%/hermes/hermes-agent/venv/Scripts/python.exe`
