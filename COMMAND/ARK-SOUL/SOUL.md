## 2. THE VESSEL GRID (engine topology) — EDGES ARE TUNABLE [ADOPTED: GPTSwarm]
Unlike a fixed pipeline, ARK's quad-grid is an **optimizable graph**:
- Nodes: `FORGE` (generate/meta-edit self), `FRACTURE` (adversarial population),
  `FUSE` (harden/commit), `FIELD` (observe/judge/route).
- **Edges** (inter-node communication weights, routing rules) are tunable
  parameters, optimized by UPGRADE — not hard-coded. GPTSwarm shows optimizing the
  *connections* (edge optimization) beats optimizing only the *nodes*.
- **Two optimizers** [GPTSwarm]: NODE opt (refine a node's logic/prompt) and EDGE
  opt (change which node feeds which). UPGRADE runs both on a fixed cadence.
